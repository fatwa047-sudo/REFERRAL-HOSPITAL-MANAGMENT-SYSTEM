🏥 Referral Hospital Management System

Project Description

Referral Hospital Management System is a web-based application designed to help manage hospital activities efficiently. It provides a centralized platform for managing patients, doctors, appointments, departments, and other hospital services.

Features

- Hospital dashboard
- Patient management
- Doctor management
- Appointment booking
- Department management
- Reception management
- Medical records management
- Pharmacy management
- Laboratory management
- Billing management
- Staff management
- Hospital reports

Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git and GitHub

Installation and Setup

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" in your web browser.
4. Start exploring the application.
